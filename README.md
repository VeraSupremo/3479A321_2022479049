## Diversificacion de pantalla y Tras

en este proyecto se busca la familiarizacion con la creacion de 
multiples ventanas en  flutter, con la finalidad de poder crear una aplicacion mas completa.

Para el laboratorio 6 se busca una conexion y union entre pantallas para poder lograr 
una aplicacion mas completa con un traspaso de datos y que estos no se reinicien cad aque se
cambia de pantalla en la aplicacion, junto a esto se aplica la posibilidad de cambiar el nombre de usuario
y un boton para activar o desactivar el boton de reset
Para el laboratorio 7 se busca lograr aprender a coenctar una base de datos, junto a
la implementacion de la persistencia de datos para evitar que cuando se pase de pagina o se salga de la app los cambios no se mantengan
